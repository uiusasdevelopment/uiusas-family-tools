# UIUSAS Clinical Suite 🧬🌐📋

Plataforma Web para criação e exportação profissional de:
- **Genograma Familiar** (Genograma Maker)
- **Ecomapa Ecológico e Social** (Ecomapa Maker)
- **Projeto Terapêutico Singular** (PTS Maker)

Desenvolvida com Tailwind CSS, Lucide Icons, SVG dinâmico, **html2canvas** e **jsPDF**.

## ✨ Recursos

- **Arrastar e Soltar (Drag & Drop):** Posicione livremente membros e instituições.
- **Clique para Editar:** Altere nomes, notas, marcadores de risco ou delete elementos com facilidade.
- **Convenções Clínicas Internacionais:**
  - Paciente índice (borda dupla)
  - Abuso de álcool [ALC] (metade inferior)
  - Gestação ($\Delta$ / G)
  - Morando junto (polígono domiciliar envolvente)
  - Vínculos: forte, fraco, conflituoso (zigue-zague autêntico), distante (-d-) e direções de fluxo
- **Exportação Dupla:**
  - 📄 **PDF:** Rigorosamente calibrado em 1 página única (A4 Paisagem para Genograma/Ecomapa e A4 Retrato para PTS).
  - 🖼️ **PNG:** Captura em alta definição ($2\times$) para anexar em prontuários eletrônicos.
